# phylocli Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Typer CLI in `Phylogenies_v3/phylocli/` that reports step2 progress per HG and submits
per-stage SLURM job arrays for chosen HGs without Nextflow, refusing any HG whose outputs exist.

**Architecture:** Per-stage shell scripts (`phylocli/stages/*.sh`) hold the step2 process bodies
and are called by both `step2.nf` and the CLI. `phylocli/core.py` holds pure logic (config, HG
sets, inputs, resources, grouping, validation); `phylocli/runner.py` runs one HG in a work dir
and publishes on success; `phylocli/phylo.py` is the Typer front end that writes sbatch array
scripts.

**Tech Stack:** Python 3.10, Typer 0.15, PyYAML, pytest; bash; SLURM (`sbatch`, `squeue`);
Nextflow 25.04 (only for the step2.nf preview check).

**Spec:** `docs/superpowers/specs/2026-09-30-phylocli-design.md` (read it first).

## Review Focus

1. HG ids with dots/underscores/hyphens (`tfs.Runt_Runx.HG1`, `tfs.T-box.HG1`, `tfs.zf-C2H2.HG111`):
   the possvm done-detection and publish globs must not mis-assign files between `…HG1` and
   `…HG11`. Test in Task 1 and Task 2.
2. A stage killed mid-publish: `status` must not count the HG as done. Publish copies the stage's
   marker file LAST, via tmp name + `os.replace`. Test in Task 2.
3. `--ids FILE` containing blank lines, trailing spaces, or ids with no cluster fasta: blanks
   ignored; unknown ids are an error listing them. Test in Task 1.
4. `submit` when some selected HGs are already running in an earlier array: whole submission
   refused, offending ids listed. Test in Task 3 (fake `squeue`).
5. `resources.tsv` values like `1140.min`, `3100.MB`, `2.GB`, `1.h`, and rows missing columns:
   parsed to SLURM `--mem=<MB>M --time=<min>`; missing -> step2 default. Test in Task 1.

### Task 3: Typer CLI and sbatch arrays

**Files:** Create `phylocli/phylo.py`, `phylocli/phylo` (chmod +x), `phylocli/tests/test_cli.py`

**Consumes:** everything from core and runner. **Produces:** commands
```
phylo status  [--ids FILE]                  # the report_status table (reuse its main logic)
phylo missing STAGE [--ids FILE]            # one id per line: expected (∩ ids) minus done[STAGE]
phylo submit  STAGE [--missing] [--ids FILE] [HG ...] [--dry-run] [--max-running N=50]
              [--partition P] [--qos Q]
phylo queue   [--stage STAGE]               # live phylo-* arrays: job id, stage, n HGs, state counts
phylo _run    STAGE HG --run-dir DIR        # hidden; used inside the array task
```
submit flow:
1. Exactly one of `--missing` / `--ids` / positional HGs, else usage error.
2. Selected = missing list, or read_ids, or positional (de-duplicated, order kept).
3. Preflight tools on PATH per stage — align: mafft, clipkit; tree: iqtree2; generax: generax,
   mpirun; gxsup: iqtree2; possvm/possvm_prev: none beyond python3 — missing -> error with the
   same hint as `submit_nf.sh` ("run 'conda activate phylo' and 'module load OpenMPI'").
4. `queued = live_hgs(stage)`: `squeue --me -h -o "%F %j"` -> live array job ids with name
   `phylo-<stage>`; map through `runs/*/jobs.tsv` (columns: job_id, ids_file) to the HG lists.
   `squeue` not on PATH -> treat as nothing queued only when `--dry-run`, else error.
5. `errs = core.validate(...)`; any non-empty -> print each category with its ids (max 20 shown,
   then "... and N more"), exit code 2, **write nothing, submit nothing**.
6. `groups = core.group(...)`; run dir `phylocli/runs/<YYYYmmdd-HHMMSS>_<stage>/` with

```bash
#!/usr/bin/env bash
#SBATCH --job-name=phylo-{stage}
#SBATCH --partition={partition}
#SBATCH --qos={qos}
#SBATCH --cpus-per-task={cpus}
#SBATCH --mem={mem_mb}M
#SBATCH --time={time_min}
#SBATCH --array=0-{n_minus_1}%{max_running}
#SBATCH --output={run_dir}/logs/{stage}_%A_%a.out
#SBATCH --error={run_dir}/logs/{stage}_%A_%a.err
{signal_line}
set -uo pipefail
HG=$(sed -n "$((SLURM_ARRAY_TASK_ID + 1))p" "{ids_file}")
echo "phylo {stage} ${HG} (array ${SLURM_ARRAY_JOB_ID}_${SLURM_ARRAY_TASK_ID})"
python3 "{root}/phylocli/phylo.py" _run {stage} "$HG" --run-dir "{run_dir}" &
PID=$!
trap 'kill -USR2 $PID 2>/dev/null' USR2
trap 'kill -TERM $PID 2>/dev/null' TERM
wait $PID; RC=$?
while kill -0 $PID 2>/dev/null; do wait $PID; RC=$?; done
exit $RC
```
`{signal_line}` = `#SBATCH --signal={signal}` or empty.
